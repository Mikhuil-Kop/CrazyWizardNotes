# CrazyWizardNotes

Головоломка / симулятор бога / симулятор волшебника.  
Игра на **Unity (C#)**.

> Статус: в активной разработке

## О проекте

CrazyWizardNotes — это головоломка в духе симулятора бога и симулятора волшебника. Игрок взаимодействует с небольшим поселением, используя разнообразные заклинания. Игра поделена на отдельные уровни, в каждом из которых нужно выполнить простое задание при помощи взаимодействующих друг с другом систем и заклинаний. Жители поселения полноценно питаются, голодают, работают и общаются. У каждого из них свое настроение (на которое в том числе способны влиять некоторые заклинания). Каждый камень, каждую дощечку, каждый кустик возможно намочить, поджечь, разогреть или сдвинуть. Гибкая архитектура со множеством абстракций позволяет создавать системы максимально проработанными и легко взаимодействующими.

Проект построен на моем собственном фреймворке **UNet**. UNet позволяет разрабатывать игру на **Unity** в стиле **ASP.NET**: использовать startup-файлы, регистрировать сервисы, внедрять зависимости через конструкторы и строить архитектуру в духе **ECS**.

Фреймворк отделяет логические сущности (компоненты) от GameObject’ов. Это даёт несколько преимуществ:

- Экономия на лишних данных, которые обычно тянут за собой MonoBehaviour’ы
- Сущности не привязаны к конкретным GameObject’ам и работают через интерфейсы компонентов
- Возможность создавать виртуальные сущности (Actor) без визуального представления в виде GameObject

Исходный код открыт для изучения и создания некоммерческих модов. После завершения игра планируется к бесплатному релизу в Steam.
